# Bibliocraft Legacy (Expanded)

Bibliocraft Legacy (Expanded) is a fork of Bibliocraft Legacy, which was a remake of the original BiblioCraft mod by Nuchaz. It adds various pieces of decorative and functional furniture into the game.
